# Персональный сайт врача — Богданова Ольга Дмитриевна

Премиальный одностраничный лендинг врача-гинеколога. Чистый HTML5 / CSS3 / vanilla JS, без сборщиков — можно открыть `index.html` напрямую или залить на любой хостинг.

## Структура проекта

```
project/
├── index.html              — главная страница (5 экранов + навбар + футер)
├── articles.html            — страница «Статьи» со списком материалов
├── mesyachnye-mify.html
├── intimnaya-gigiena.html
├── pervyy-vizit-ginekolog.html
├── vpch-vakcinaciya.html
├── boleznennye-mesyachnye.html   — 5 отдельных страниц-статей
├── sitemap.xml              — карта сайта для Search Console (см. ниже)
├── robots.txt                — указывает поисковикам на sitemap.xml
├── css/
│   └── style.css           — дизайн-система, layout, анимации, адаптив
├── js/
│   └── script.js           — navbar при скролле, floating CTA, мобильное меню, лента отзывов, AOS
├── images/
│   ├── doctor-main.webp          — Hero (заглушка, см. ниже)
│   ├── doctor-consultation.webp  — экран «Подход к пациенту» (заглушка)
│   └── doctor-card.webp          — финальный экран записи (заглушка)
└── README.md
```

## Куда вставить реальные фотографии

Сейчас в `images/` лежат нейтральные фоновые заглушки (сгенерированы, не фотографии), чтобы страница сразу выглядела собранной. Замените их на настоящие фото **с теми же именами файлов** — тогда ничего в коде менять не нужно:

| Файл | Где используется | Рекомендации |
|---|---|---|
| `images/doctor-main.webp` | Hero, экран 1 | Портрет врача, вертикальная ориентация (соотношение ~4:5), крупный кадр |
| `images/doctor-consultation.webp` | Экран 3 «Подход к пациенту» | Врач с пациенткой, горизонтальный кадр |
| `images/doctor-card.webp` | Экран 5 «Запись на прием» | Любой сильный портретный кадр, квадратная обрезка подойдёт лучше всего |

Формат WebP уже оптимален для веба; если фото в JPG/PNG — можно оставить как есть, просто обновите расширение в `src` в `index.html` (3 места) и в `og:image`.

## Что легко редактировать

- **Текст, ФИО, специализации, телефон, адреса** — прямо в `index.html`, всё на русском языке и структурировано по секциям с комментариями `<!-- ЭКРАН ... -->`.
- **Ссылка записи на ProDoctorov** — используется в 4 местах (Hero, navbar, floating-кнопка, финальный CTA). При необходимости замените глобальным поиском по `prodoctorov.ru`.
- **Цвета** — все значения собраны в `:root` в начале `style.css` (`--primary`, `--accent`, `--background` и т.д.).
- **Отзывы** — в блоке `#reviews` карточки идут по порядку; 4 реальных отзыва + 3 подготовленных пустых слота (`review-card--empty`) для будущих отзывов.
- **Карта** — сейчас встроен Яндекс.Карты iframe с приблизительными координатами Ставрополя. Рекомендуется заменить на точный embed-код с реальными координатами обоих адресов (Яндекс.Карты → «Поделиться» → «Код для сайта»).

## SEO: заголовки, описание, sitemap

**Title и description** уже настроены в `index.html`:
- `<title>Доктор Богданова — гинеколог | Приём в Ставрополе</title>`
- `<meta name="description" content="...">` — 160 символов, укладывается в рекомендованный диапазон 150–160.
- `<h1>` на главной содержит имя и специализацию: «Доктор Богданова / Ольга Дмитриевна — гинеколог».

У каждой статьи и у страницы «Статьи» — свои уникальные `<title>` и `<meta name="description">`.

### Домен в sitemap.xml и robots.txt — обязательно замените

Домен уже настроен: `https://doctor-bogdanova.pro/` — прописан в `sitemap.xml`, `robots.txt`, а также в `canonical`, `og:url` и `og:image` на каждой странице.

### Как добавить sitemap в Google Search Console

1. Зайдите на [search.google.com/search-console](https://search.google.com/search-console) и выберите ваш сайт (если сайт ещё не добавлен — сначала подтвердите права на него через DNS-запись или HTML-файл, который предложит сама Search Console).
2. В левом меню откройте **Индексирование → Файлы Sitemap**.
3. В поле «Добавьте новый файл Sitemap» введите `sitemap.xml` (полный адрес получится `https://doctor-bogdanova.pro/sitemap.xml`).
4. Нажмите **Отправить**.
5. Статус обработки появится в списке ниже — обычно занимает от нескольких часов до пары дней.

Sitemap должен быть физически доступен по адресу `https://doctor-bogdanova.pro/sitemap.xml` — то есть файл `sitemap.xml` нужно залить в корень сайта вместе с остальными файлами проекта.

## Как добавить новую статью

1. Скопируйте один из готовых файлов статей (например, `mesyachnye-mify.html`) и переименуйте в новый slug латиницей (например, `novaya-statya.html`).
2. Замените `<title>`, `<meta name="description">`, `<h1 class="article-page__title">` и содержимое `.article-content` на текст новой статьи.
3. В `articles.html` добавьте новую карточку `.article-card` в `.articles__grid` (сетка уже готова под 8–10 карточек — просто скопируйте один из существующих блоков `<article class="article-card">`).
4. При желании — добавьте новую страницу в `sitemap.xml`.
